The matrix separates code that is operational in the current implementation from the extent of test evidence and capabilities that remain missing or unaccepted. “Operational” does not imply Windows, live-service, production deployment, or user-facing product acceptance.

## Verification

The desktop syntax checks and Node suite completed with **5 passed** (`cd desktop && npm run check && npm run test:desktop`). The focused graph/runtime, crash-recovery, execution-fence, and delegated-tool-scope suites completed with **57 passed**. `git diff --check` reported no whitespace errors. Targeted counts overlap with the full suite and must not be added together.

The new fan-out tests use deterministic executor/tool doubles and prove bounded control flow, task isolation, fence enforcement, deterministic fan-in, and fail-closed crash quarantine only. They do **not** prove actual parallel production tool execution or local Qwen/Mission behavior. The suite does not prove live search availability, Windows installation, real model inference, running-task cancellation/backoff, browser/MCP, production Skill dispatch, complete Owner-facing APIs/UI, or Hermes-level completeness.
