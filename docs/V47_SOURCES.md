# V4.7 Cyber Intelligence Sources and Safety Policy

V4.7 treats external cybersecurity material as **untrusted reference data**, not as Owner policy and never as an authorization source. Every imported object must retain its source URL, immutable revision or release, retrieval time, parser version, content hash, license or attribution metadata, and validation result. Raw material and normalized material remain separate so that later review can reproduce the transformation.

## Normalization pipeline

The ingestion path is intentionally staged: **raw snapshot → schema validation → normalization → deduplication → quality filter → provenance index → local retrieval**. `cyber_knowledge.models.normalize()` rejects unknown fields, unsupported source types, invalid confidence, future dates, and content-hash mismatches. `cyber_data.ingestion.load_jsonl()` keeps the original source identity while dropping duplicate content hashes and very short observations; `quality_filter()` applies the minimum confidence and provenance requirements.

The retrieval layer returns only local `object_id`, score, source, source type, content hash, observation, and technique. It does not return executable commands or grant tool permissions. The Owner-only `red_team_assess` capability consumes observations and produces competing hypotheses, required evidence, uncertainty, and limitations. It does not exploit, scan, execute shell, retrieve credentials, or dispatch network actions.

## Licensing and poisoning policy

Source attribution is not a blanket redistribution license. The implementation must preserve repository/file license notices and review source-specific terms before export or model training. Dataset and rule text can contain prompt injection, stale claims, secrets, personal data, or offensive procedures. Such content is displayed as escaped data, quarantined when necessary, and never inserted into the system policy or executed. Any future active assessment capability requires a separate Owner-policy review, a bounded target scope, an isolated executor, and new adversarial tests.
