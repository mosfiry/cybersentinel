## Obligations and implementation decision

The implementation in CyberSentinel uses **independent source code**. The projects are not dependencies of CyberSentinel, and no third-party source file or substantial code portion was copied. Consequently, the source-license obligations listed above are recorded for future compliance but no third-party copyright notice was introduced into runtime files for copied code.

If a future change copies source rather than reimplementing a concept, the relevant license text, copyright notices, modification notices, and dependency obligations must be added before merge. AutoGen requires special asset-by-asset review because its top-level documentation/assets and source code have different license surfaces. Qwen-Agent requires Apache notices and patent/trademark care. All dependency licenses remain a separate SBOM/compliance task.
