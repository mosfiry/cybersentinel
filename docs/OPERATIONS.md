# Final operation

1. Create `.env` from `.env.example`.
2. Put a fresh random BRIDGE_TOKEN in `.env`.
3. Run `python -m compileall -q core bridge.py`.
4. Run `python bridge.py`.
5. Open `http://127.0.0.1:8787/` on the same device.
6. Enter the token when prompted.

First commands:
- `حدّث استخبارات التهديدات`
- `افحص الجهاز محليًا`
- `اعرض أحدث الثغرات`
- `ابحث عن CVE-`
- `راقب nginx`

The first two perform real local/network defensive collection.
