## العقد والحدود

مكوّن مستقل يستدعيه كود broker موثوق ذو امتيازات فقط؛ حجم ثابت صريح ومحدود لكل تشغيل وهوية مولّدة داخليًا. يبدأ من root محلي موثوق لا يمكن لطرف غير موثوق تعديله، ويرفض reparse paths. إنشاء/إرفاق/تهيئة/تركيب وتنظيف مملوك لهذه الهوية وحدها. لا shell interpolation لمسارات؛ APIs أصلية وسكربت ثابت مع بيانات منظمة فقط. فشل الإعداد يمنع تسليم مساحة جاهزة؛ فشل التنظيف ظاهر ويحتفظ بهوية المورد ولا يدعي حذفه.

لا توصيل بـMissionRuntime أو process launch أو الأدوات، ولا broker service أو grant جديد. لا تغيير لـOwner/Scope/Fence/limits أو `RESOURCE_BLOCKED`. حد القرص وحده ليس sandbox؛ AppContainer/ACL والشبكة وحصر كل temp/profile/child paths غير مكتملة. لا تغيير لـmain أو releases/tags أو Cloudflare.

## المخاطر

CI Windows إداري لكنه لا يثبت broker منتج أو حصر وصول عملية مشروع. فشل capability اختبار فاشل لا skip. أي فشل تنظيف يوقف التسليم ويترك المورد للاسترداد الموثوق؛ لا recursive deletion عبر mount. انهيار broker/انقطاع الجهاز يحتاج لاحقًا بروتوكول recovery وجرد موارد، ولا يبرر تفعيل backend.
