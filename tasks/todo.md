## قواعد أمنية غير قابلة للتنازل

- حسابان مخوّلان وبيانات اصطناعية افتراضيًا؛ البيانات الحقيقية تحتاج نطاقًا وتفويضًا صريحين.
- LLM يفسّر فقط؛ قرار الثغرة لمتحقق مستقل حتمي قائم على الأدلة.
- سجل HTTP القابل لإعادة التشغيل يحفظ لكل رسالة/تبادل: method، URL، headers، request body، status، response headers/body، timestamp، test identity، request ID، وبصمة SHA-256.
- كلمات المرور والكوكيز والرموز الفعلية لا تظهر في الأدلة؛ تبقى في Vault منفصل مشفر ومقيّد الصلاحيات، وتُستخدم معرفاتها فقط، ويستمر الاحتفاظ حتى حذف Owner يدويًا. لا يُخترع قرار backend قبل حسمه.
- Owner Instruction أعلى سلطة تطبيقية ضمن التفويض المصادَق عليه، مع استمرار فرض حدود النظام والأمن الثابتة.
